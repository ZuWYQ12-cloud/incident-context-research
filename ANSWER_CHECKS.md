# Ограниченная проверка ответа модели

Версия 1 содержит две эвристики. Они показывают замечания и цитаты, но не
исправляют исходный ответ, не меняют ручную оценку и не объявляют диагноз верным.

1. Проверка наличия идентификатора среди observations исходного запроса.
   Распознаются HTTP-N, EN и отдельные ссылки [API], (API), ID: API и аналогичные DB.
   Не все способы записи ссылок поддерживаются. Существование ссылки не доказывает,
   что она поддерживает утверждение; неверное использование API как момента времени
   этой проверкой не выявляется.
2. Предупреждение о возможном ошибочном приписывании отказа БД. Оно появляется,
   если HTTP-сборщик зарегистрировал Connection refused без HTTP-кода, в ответе
   есть определённые утвердительные фразы про БД, а известные шаблоны ошибок
   соединения с БД в переданных журналах не найдены. Отсутствие шаблона не доказывает
   исправность БД. Если шаблон есть, это также не подтверждает причинный вывод модели.

Оговорки «не подтверждено», «гипотеза», «возможно», «проверить» в той же строке
подавляют вторую эвристику. Это ограниченный разбор формулировок: он может пропускать
ошибки и давать ложные срабатывания. Сложные отрицания и несколько утверждений
в одной строке требуют ручной проверки. Код 200 и последовательность времён пока
автоматически не оцениваются.

Источником для проверки служит исходный observations-блок сохранённого prompt.txt.
Просмотрщик сначала сверяет хеш запроса, снимок источников и запрос генерации.
Если формат запроса не распознан, показывается «проверка не выполнена», а не успех.
Замечания рассчитываются при просмотре; старые ответы не переписываются.

review_model_comparison.py сохраняет JSON и Markdown для двух существующих запусков.
Перед сохранением сверяет источники, модель, ревизию, seed, параметры генерации,
dtype, режим thinking, версии библиотек и GPU. Файлы результатов не перезаписывает.
В отчёте сохраняются хеши ответов, метаданных и версия эвристик. Это подготовительная
проверка, а не независимая экспертная оценка или статистическое доказательство.
