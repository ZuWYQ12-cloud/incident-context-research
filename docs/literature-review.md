# Обзор литературы

Начальный список из обсуждения. Перед включением утверждений в ВКР проверить полный текст, версию публикации и страницы. Сходство идеи не доказывает воспроизводимость метода.

| Работа | Источник | Что проверить |
|---|---|---|
| RCACopilot | https://tianyin.github.io/pub/rca-copilot.pdf | Сбор контекста, время исторических случаев, категории причин |
| RCAgent | https://arxiv.org/abs/2310.16340 | Инструменты агента, доступные события, альтернативные объяснения |
| Log-Insight | https://arxiv.org/abs/2607.08529 | Сжатие контекста, временные сведения, сравнение ошибок и успехов |
| Gandalf | https://www.usenix.org/system/files/nsdi20-paper-li.pdf | Атрибуция сбоев изменениям, временные и пространственные связи |
| Aegis | https://www.microsoft.com/en-us/research/wp-content/uploads/2022/12/seip23_ageis_cameraReady.pdf | Изменения и оценка их влияния |
| ChangeRCA | https://github.com/IntelligentDDS/ChangeRCA | Выбор дефектного изменения, данные и ограничения |
| EoG | https://arxiv.org/abs/2601.17915 | Граф, локальное рассуждение, пересмотр гипотез |
| RCAEval | https://github.com/phamquiluan/RCAEval | Пригодность данных и наличие истории изменений |

Для каждой работы заполнить: задача; данные; учёт изменений; время; альтернативные причины; метрики; ограничения; отличие нашего эксперимента. Не заявлять новизну до завершения сопоставления.
