# Проверка технических рекомендаций

Проверка выполнена по официальной документации PostgreSQL 17
и Docker Compose после подготовки черновых оценок.
Рекомендации модели на стенде не выполнялись.

## Подтверждённые свойства

pg_isready проверяет состояние подключения к PostgreSQL.
Он не определяет инициатора или причину прошлой остановки.

pg_stat_activity является представлением текущей активности.
SQL-запросы к нему требуют подключения к работающему серверу.
Это не самостоятельная команда оболочки.

psql с параметрами подключения и -c "SELECT 1" является
допустимым способом проверки подключения и выполнения SQL.
Примерные параметры требуют адаптации к стенду.

Имена сервисов Docker Compose разрешаются в общей сети
контейнеров. При проверке имени db необходимо учитывать,
откуда выполняется запрос.

Назначение /health/live определяется нашим приложением:
этот обработчик не обращается к БД. Предложение использовать
его для проверки PostgreSQL противоречит входному контексту.

## Правила интерпретации оценок

Отсутствие готовой команды само по себе не является ошибкой.
Оцениваются полезность, конкретность и применимость проверки.

Примерные параметры не считаются выдуманными фактами,
если модель не утверждает, что это реальная конфигурация.

Проверка текущего состояния не восстанавливает историю сбоя
без сохранённых наблюдений. Повторное чтение уже предоставленных
сообщений не гарантирует получения новых доказательств.

Одинаковый балл за дополнительные проверки не означает,
что ответы содержат одинаковые дефекты. Основания указаны
в отдельных оценках.

Проверены перечисленные выше средства. Полная проверка
всех упомянутых сетевых утилит ещё не выполнена.
Оценки остаются предварительными.
