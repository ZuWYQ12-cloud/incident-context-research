# Инцидент 003: отказ чтения таблицы

Дата: 2026-11-12.
Стенд: Docker Compose, API и PostgreSQL.
Исходные материалы: results/raw/20261112T144344Z-table-permission.

## Вмешательство оператора

Создана роль diag_reader_003 с парольным входом, доступом
к базе production, схеме public и правом SELECT на
public.production_tasks.

Подключение роли и чтение таблицы предварительно проверены.
API переключён на эту роль отдельной конфигурацией
stand/compose.table-permission.yaml.

Для воспроизведения отказа отозвано право SELECT.
Для восстановления право возвращено командой GRANT SELECT.

Эти сведения описывают вмешательство оператора.
Их нельзя включать в диагностический запрос как наблюдения,
если проверяется способность системы установить причину.

## Особенности выполнения

Команда отзыва права не вернула управление терминалу.
Отдельная проверка has_table_privilege показала false.

Команда восстановления вывела GRANT, но завершилась
по тайм-ауту с кодом 124. Восстановление чтения подтверждено
последующими успешными запросами ready и tasks.

Коды выгрузки журналов сохранены отдельно.
Полнота журналов не считается подтверждённой автоматически.

API после эксперимента остаётся под ролью diag_reader_003.
У неё восстановлено чтение; права записи не выдавались.
