# Временной и сетевой контекст инцидента

Цель изменения — сделать явными границы наблюдений, чтобы модель не переносила
успешные HTTP-коды до сбоя на последующие отказы и не относила отказ подключения
монитора к API к соединению API с БД. Улучшение ответов ещё не доказано.

prepare_incident_model.py теперь поддерживает --context-mode baseline и timeline.
По умолчанию новые запросы, в том числе по кнопке интерфейса, используют timeline.
Ранее сохранённые запросы и ответы не переписываются. Интерфейс по-прежнему показывает
model-review-001 и не заменяет его новым результатом.

Исходные observations и rule_findings сохранены. Дополнительный блок вычисляется
из тех же данных и явно обозначен как производный указатель. Для строк журналов
сохраняются идентификатор источника и номер строки. Время — метка Docker, не
гарантированное время события приложения. Синхронизация часов не проверена.
Часовые пояса учитываются; точность до наносекунд сохраняется без float.

Границы — первый неуспешный замер и подтверждение инцидента. Первый замер не считается
точным моментом начала отказа. Интервал HTTP-проверки, пересекающий границу,
отмечается отдельно. Неизвестное, некорректное или время без часового пояса
не восстанавливается предположениями. Время получения журнала не заменяет время строки.
Граница восстановления в этом снимке отсутствует; «после подтверждения» не означает
«всё ещё во время отказа».

Направление monitor_to_api задаётся только для HTTP-наблюдений сборщика.
client_to_api задаётся для явных структурированных записей http_request API;
личность клиента из этого не выводится. Остальные строки имеют connection=unknown.
Автоматическое распознавание API → БД в этой версии не реализовано: модели нужна
явная запись о таком соединении. Имя источника DB или слово connection не достаточны.

В папке нового запроса сохраняется context-index.json. preparation.json содержит
режим, хеш указателя и хеш его построителя. Хеш самого запроса сохраняется как прежде.
Прежний предел 30000 символов действует и на расширенный запрос: при превышении
генерация не запускается, исходный текст не обрезается скрыто.

Для сравнения используйте один сохранённый инцидент и две новые папки:

```bash
python3 src/prepare_incident_model.py "$INCIDENT" --context-mode baseline --output-dir "$INCIDENT/comparison-context-001/baseline"
python3 src/prepare_incident_model.py "$INCIDENT" --context-mode timeline --output-dir "$INCIDENT/comparison-context-001/timeline"
```

Перед сравнением сверьте source_sha256 обоих preparation.json. Параметры модели,
seed и лимит ответа должны совпадать; стоимость дополнительного контекста учитывается
отдельно. Этот инцидент использован при разработке, поэтому является подготовительным,
а не независимым итоговым испытанием. Не заменяйте вручную текст сохранённого ответа.
