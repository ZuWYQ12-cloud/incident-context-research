# Исследование диагностического контекста

Магистерское исследование влияния состава контекста на качество определения причин сбоев программных сервисов локальными языковыми моделями.

Направление: 09.04.03 «Прикладная информатика», «Цифровая аналитика производственных систем», ГУАП.

Главный результат — результаты экспериментов, анализ ограничений и выводы. Программный стенд служит инструментом исследования. Научная новизна пока требует обоснования по литературе.

## Исследовательский вопрос

Помогают ли сведения об изменениях, последовательности событий и альтернативных причинах уменьшить ошибочное обвинение последнего развёртывания без существенной потери способности обнаруживать действительно вызванные им сбои?

## Начало работы

1. Прочитать [паспорт исследования](docs/research-passport.md).

3. Зафиксировать версии инструментов и результаты в [журнале исследования](docs/research-log.md).

## Структура

- `docs/` — паспорт, обзор литературы, журнал и план.
- `experiments/` — протоколы экспериментов.
- `src/` — будущий код подготовки контекста и оценки.
- `data/` — локальные данные; правила хранения описаны внутри.
- `results/` — небольшие проверенные отчёты; большие артефакты исключены из Git.
