# Данные

Наборы данных не добавляются в Git автоматически. Хранить исходные наблюдения, входы модели и истинные причины отдельно. Для воспроизводимости записывать источник, лицензию, версию, контрольную сумму, способ подготовки и разбиение. Не включать секреты или персональные данные. Не передавать модели метки причин и будущие события.
