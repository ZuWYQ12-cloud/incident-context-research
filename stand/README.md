# Экспериментальный стенд

Учебный сервис учёта производственных заданий:
FastAPI + PostgreSQL 17, запуск через Docker Compose.

Все команды выполняются из корня репозитория.

## Запуск

```bash
sudo docker compose -f stand/compose.yaml up -d --build
sudo docker compose -f stand/compose.yaml ps
```

API доступен по адресу http://127.0.0.1:8000.
Интерактивное описание API: http://127.0.0.1:8000/docs.

## Проверки

```bash
curl -i --max-time 10 http://127.0.0.1:8000/health/live
curl -i --max-time 10 http://127.0.0.1:8000/health/ready
curl -sS --max-time 10 http://127.0.0.1:8000/tasks
```

- /health/live проверяет доступность приложения.
- /health/ready проверяет доступ к таблице production_tasks.
- POST /tasks создаёт задание.
- PATCH /tasks/{task_id} изменяет его статус.
- GET /tasks возвращает первые 100 заданий.

## Журнал

```bash
sudo docker compose -f stand/compose.yaml logs --tail=50 api
```

JSON-записи содержат идентификатор запроса, время начала
и завершения в UTC, метод, путь, HTTP-статус, длительность
и тип необработанного исключения.

## Остановка

```bash
sudo docker compose -f stand/compose.yaml down
```

Данные сохраняются в томе postgres_data.
Параметр down -v удаляет том и данные — для обычной остановки
его использовать не нужно.

## Особенности

- Пароль в Compose демонстрационный, только для локального стенда.
- init.sql выполняется автоматически только при пустом каталоге БД.
- Изменения кода приложения требуют пересборки образа.
- Версии Python-библиотек зафиксированы в requirements.lock.txt.
- Базовые образы пока заданы изменяемыми тегами.
